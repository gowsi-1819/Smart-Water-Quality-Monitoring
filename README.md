# Smart Water Quality Monitoring System (Java)

## Description
This project analyzes basic water quality parameters such as pH, turbidity, and TDS to determine whether water is safe for consumption. It also provides a rule-based indication of potential waterborne disease risks.

## Technologies Used
- Java
- Core Java concepts
- Scanner class
- Conditional statements
- Methods

## Input Parameters
- pH value
- Turbidity (NTU)
- Total Dissolved Solids (mg/L)

## Output
- Water quality status (SAFE / UNSAFE)
- Possible waterborne disease risk (rule-based)

## Note
This project is for educational purposes only and does not provide medical diagnosis.
