# Smart Water Quality Monitoring System (Java)

## Description
This project analyzes basic water quality parameters such as pH, turbidity, and TDS to determine whether water is safe for consumption. It also provides a rule-based indication of potential waterborne disease risks.

## Technologies Used
- Java
- Core Java concepts
- Scanner class
- Conditional statements
- Methods

## Input Parameters
- pH value
- Turbidity (NTU)
- Total Dissolved Solids (mg/L)

## Output
- Water quality status (SAFE / UNSAFE)
- Possible waterborne disease risk (rule-based)

## Note
This project is for educational purposes only and does not provide medical diagnosis.

## Future Enhancements
- IoT sensor integration
- Database connectivity
- Real-time monitoring dashboard
- Machine learning-based prediction

- ## How to Run
1. Compile the program:
   javac Main.java WaterQualityChecker.java
2. Run the program:
   java Main

## Sample Input
pH: 7.2  
Turbidity: 3  
TDS: 300  

## Sample Output
Water Quality Status: SAFE  
Health Advisory: No significant waterborne disease risk detected
